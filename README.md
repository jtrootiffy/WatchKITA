## 📖 The Story Behind the Name

The name **WatchKITA** brings together two intertwined concepts rooted in language and cinema:

* **Watch** — represents the visual act of watching cinema, television series, and storytelling on screen.
* **KITA** — means **"us"** (the inclusive *we*) in **Waray-Waray**, a major native language spoken across the Eastern Visayas region of the Philippines. In Filipino and Waray-Waray idioms, *"kita"* also shares phonetic meaning with seeing or meeting.

Together, the phrase mirrors the beloved colloquial expression **"Kita-kita"** — meaning *"let's see each other"* or **"let's watch, together."** 

WatchKITA turns personal streaming into a shared communal sentiment: entertainment is best enjoyed when shared with others, whether huddled around a television with family or streaming synchronously across miles.

**WatchKITA** is an editorial, dark-themed streaming web application and comprehensive title discovery guide designed for movies and television series. Built with a theater-dark aesthetic (`#0C0A0C`), it gives film lovers and series bingers a distraction-free environment to discover what's new, read comprehensive synopsis and cast directories, track titles in a personal watchlist, and jump straight into streaming playback.

## ✨ Features

Every feature listed below is verified and directly implemented in the WatchKITA codebase:

* **Integrated CineSrc Streaming Player**
  * Direct in-app video playback for both movies (`/watch/movie/:tmdbId`) and episodic television series (`/watch/tv/:tmdbId`).
  * Dynamic season and episode selection interface with episode runtime, air dates, and individual synopses.
  * Autoplay, autonext episode chaining, and theater-frame view with quick navigation back to title details.
* **Unified Catalog Browser (`/movies`, `/tv-shows`, `/discover`)**
  * Shared browsing engine across movies and TV series.
  * Real-time multi-genre selection chips with instant dismiss.
  * Release year range filtering (from custom start year to end year).
  * Multiple sort algorithms: Popularity, Vote Average / Rating, Release Date, and Title Alphabetical.
  * Infinite load-more pagination with cached state preservation.
* **Rotating Featured Hero Showcase (`/`)**
  * High-impact hero carousel displaying trending cinematic releases.
  * Real-time ratings, release year, runtime, genre tags, and overview synopsis.
  * One-click "Watch Now" action linking directly to the streaming player.
  * Immediate "+ Watchlist" toggle button on the hero banner.
* **Full-Screen Debounced Search Overlay**
  * Instant modal overlay activated from the navigation bar or keyboard shortcuts.
  * Debounced queries to fetch live title suggestions with minimal latency.
  * Recent search query history stored locally for rapid re-searching.
  * Full search result views via `/search` and `/tmdb-search`.
* **Rich Title Details Experience (`/title/:id`)**
  * High-resolution artwork, widescreen backdrops, and official poster cards.
  * Full metadata: year, age classification rating, runtime, and TMDB audience scores.
  * Embedded official YouTube trailer viewer.
  * Full Cast & Crew directory with character names, actor headshots, and director credits.
  * Comprehensive TV series breakdown with all seasons and individual episodes.
  * "Similar Titles" recommendation rail based on genres and themes.
* **Regional Watch Providers**
  * Live availability data categorized by business model: Subscription (SVOD), Free (AVOD), Digital Rental, and Digital Purchase.
  * Powered by TMDB watch provider feeds to identify legal streaming platforms worldwide.
* **Device-Synced Personal Watchlist (`/watchlist`)**
  * One-tap save action on any title card, hero banner, or detail page.
  * Switch between responsive Grid View and dense List View.
  * Filter saved items by Movies vs. TV Shows.
  * Offline-first persistence via browser LocalStorage with remote synchronization via Supabase.
  * Per-item removal and confirmed "Clear All" modal to prevent accidental deletion.
* **Region Switching**
  * Change regional preferences on the fly (e.g. US, GB, CA, AU, PH) to adapt watch provider availability and localized catalog results.
* **Performance & Accessibility**
  * Framer Motion transitions with full support for `prefers-reduced-motion`.
  * Mobile-first responsive navigation bar with sliding mobile drawer.
  * In-memory and remote cache optimization using TanStack Query.

## 🛠️ Technology

WatchKITA is powered by a modern, full-stack TypeScript architecture:

* **Frontend Client**
  * **React 18** with **Vite 5** for fast modular rendering and optimized production builds.
  * **TypeScript 5** for strict end-to-end type safety.
  * **Tailwind CSS** for theater-dark utility styling and responsive layouts.
  * **Framer Motion** for smooth page transitions and micro-interactions.
  * **TanStack Query (React Query)** for client-side caching, background refetching, and query deduplication.
  * **React Router 6** for seamless single-page application routing.
  * **Lucide React** for clean, accessible interface icons.
* **Backend Server & Serverless**
  * **Express 4** running on **Node.js** with modular route handlers.
  * **Helmet** and strict **CORS** configuration for production security.
  * **express-rate-limit** for burst protection and upstream request throttling.
  * **Vercel Serverless Integration** via `api/index.ts` and `vercel.json` rewrites.
* **Catalog & Streaming Integrations**
  * **The Movie Database (TMDB) API** for search, discover rails, detailed filmographies, high-resolution imagery, and regional watch providers.
  * **CineSrc Player Engine** for embedded video streaming across movies and TV series.
* **Persistence & Caching**
  * **Supabase (PostgreSQL)** for server-side response caching (`api_cache`) and durable device-linked watchlist storage (`watchlist_items`).
  * **Browser LocalStorage** for instantaneous offline-first watchlist access.
